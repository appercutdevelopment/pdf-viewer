# PDF Viewer

Open and read PDF files directly inside VS Code — no external app required.

## Features

- **Instant preview** — click any `.pdf` file in the Explorer to open it in the editor
- **Page navigation** — previous/next buttons, jump-to-page input
- **Zoom** — zoom in/out, fit to width, fit to page
- **Text search** — `Ctrl+F` / `Cmd+F` to search within the document
- **Text selection** — select and copy text from the PDF
- **Outline / bookmarks** — sidebar panel for documents that include a table of contents
- **Thumbnails** — thumbnail strip for quick page browsing
- **Print** — print directly from the viewer toolbar

Powered by [PDF.js](https://mozilla.github.io/pdf.js/) — the same engine used in Firefox.

## Usage

Open any `.pdf` file from the VS Code Explorer or with **File → Open**. The PDF Viewer opens automatically as the default editor for `.pdf` files.

To switch back to the raw binary view, right-click the file → **Open With… → Text Editor**.

## Requirements

VS Code 1.85 or later.
